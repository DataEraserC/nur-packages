# browser4 单包经验

- **拆包结构**：`browser4-unwrapped/` 是未包装构建（runtime + 裸 CLI，构建侧经验见 [`../browser4-unwrapped/AGENTS.md`](../browser4-unwrapped/AGENTS.md)）；本目录只有薄包装层——`ln -s` 未包装产物再 `wrapProgram`，经 `unwrapped ? pkgs.callPackage ../browser4-unwrapped { }` 按需求值，`version`/`runtime`/`tag` 全部 `inherit` 自未包装层。包装层**不引用 `sources.`**（`helpers/update.nix` 的 `usesSources` 过滤器据此跳包），版本更新只改 unwrapped 目录。
- wrapper 合同（`postFixup` 按序生效）：`--set-default BROWSER4_CLI_FORCE_REMOTE_BUNDLE 1`（禁止 CLI 探测本地源码 checkout）；`--set-default BROWSER4_RUNTIME_DIR <unwrapped.runtime>/share/browser4`（免除首跑 127MB 下载）；`--run` 建日志目录（坑 1）；`--run` P2 警告（坑 2）；`--run export BROWSER4_SERVER_OPTS="-Dlogging.dir=…"`（logback 的 -D 后写覆盖前写，防止日志落到只读 CWD）；`--run` 扫参在 `install`/`upgrade` 未显式给 `--tag` 时注入 `--tag v4.13.23`——上游 v4.13.24 起 release 无资产，裸装会拉空。
- **makeWrapper 生成的包装脚本 shebang 带 `-e`（`bash -e`）**：任何 `--run` 片段返回非零都会中止整个 CLI。故片段写法必须容错——建目录片段用 `if [ -n "$d" ] && [ ! -d "$d/logs" ]; then mkdir -p … || echo warning >&2; fi`（mkdir 失败降级为 stderr 警告，绝不退出）；`--set-default` 必须写在读取该变量的 `--run` 之前（片段按参数顺序逐行写入包装脚本）。`versionCheckHook` 用 `env --ignore-environment` 跑二进制（无 HOME、无 PATH），所以建目录守卫在 `HOME` 未设时必须跳过，构建期才不会失败。
- 会话实测三坑（session-4fbf40c6，/home/nixos/tmp 下尝试 browser4-cli）：① **P1 日志目录缺失**——后端崩溃 `FileNotFoundException ~/.browser4/logs/pulsar.dc.log`，wrapper 设了 `-Dlogging.dir` 却从不 mkdir；现由 wrapper `--run` 守卫自动建 `BROWSER4_CLI_STATE_DIR`（缺省 `~/.browser4`）下的 `logs/`，smoke 已验（含自定义 STATE_DIR 路径）。② **P2 覆盖 `BROWSER4_RUNTIME_DIR` 会触发 121.5MB 重下载**未打补丁的 v4.13.24 运行时——ELF PT_INTERP 是 `/lib64/ld-linux-x86-64.so.2`，NixOS 上报 nix-ld 错（会话里被迫手 patchelf 5 个文件），且 CLI/后端版本错位；**用户覆盖 `BROWSER4_RUNTIME_DIR`（且不在 /nix/store 下）时包装层向 stderr 打警告**，smoke 已验（未覆盖 0 条 / 覆盖 1 条）。**NixOS 上永远不要覆盖 `BROWSER4_RUNTIME_DIR`**，要换位置请用本包装自带的 store 运行时；确实需要写目录时改 `BROWSER4_CLI_STATE_DIR`（只影响状态与日志）。③ **P3 后端被回收**——DSH `bash` 工具调用结束时子进程全被杀，`goto` 自动拉起的 server 随调用结束消失（"No active session"），CLI 也没有 `start`/`serve` 子命令。**不要用 systemd 服务解决**（用户明确否决）；正确做法是把后端放进 harness 后台任务：`bash(run_in_background=true)` 里 `export BROWSER4_RUNTIME_DIR=… BROWSER4_CLI_STATE_DIR=…` 后跑需要 server 的命令，或单独起一条保持 server 的长任务，轮询 `http://localhost:8182/actuator/health` 到 `UP` 再继续；任务结束用 `job_kill` 收尾。
- NixOS 入口：`modules/browser4.nix` 提供 **`programs.dataEraserc.browser4`**（`enable`/`package`/`browserPath`，无 systemd；用户确认的命名空间例外），`flake.nix` `# My additions` 注册；`browserPath` 非空时导出 `environment.sessionVariables.BROWSER4_BROWSER_PATH`；`package` 缺省 `pkgs.browser4 or null`，无 overlay 时由 assertion 给可读报错。nix-config 侧对应 `modules.browser4.enable` 薄封装（`modules/nixos/base/custom/browser4.nix`），dsh 配置已迁移到 `modules.browser4.enable = lib.mkDefault true`。
- 运行注意：`upgrade --force` 与技能下载仍需网络（超出包装控制范围）；`BROWSER4_SERVER_OPTS` 按空白切分、`is_jvm_option` 只认 `-D`/`-X`/`--add-`（上游限制）；快照 `https://example.com` 曾返回阿拉伯语占位页（疑似网络劫持，非打包问题）。
