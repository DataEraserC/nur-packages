# bqqnt（在 nixpkgs `qq` 之上只加一层）

- **依赖 `pkgs.qq`（nixpkgs），不要依赖 fork 自带的 `pkgs/uncategorized/qq`**：`createCallPackage` 用 `callPackageWith (pkgs // _packages // …)`，自有同名包会遮蔽 nixpkgs 版本，`qq` 形参拿到的是自有旧版（3.2.18，wrapper 没有 Wayland flag）；自写启动脚本 `exec ${qq}/bin/qq` 会丢掉 nixpkgs `qq` wrapper 在 `NIXOS_OZONE_WL`+`WAYLAND_DISPLAY` 下加的 `--ozone-platform=wayland --enable-features=WaylandWindowDecorations --enable-wayland-ime=true --wayland-text-input-version=3`，Wayland 下 Electron 既不建 text-input 也不走 XIM，fcitx5 完全打不出中文。把 `pkgs` 写进参数表再用 `pkgs.qq`（nixpkgs 的 `pkgs.pkgs` 存在，注入的合并集里取得到），版本与依赖就跟着 flake.lock 走，不必在本仓库维护上游派生；本包无 `passthru.updateScript`，更新跟随 flake.lock（`helpers/update.nix` 的 excludes 注释即指这类纯 wrapper）。
- **只加一层用 `symlinkJoin { paths = [ pkgs.qq ]; … }`**：`lndir` 造真目录 + 文件 symlink，`bin/qq`、`share/applications/qq.desktop` 与图标都是上游自己的文件，原版入口天然带 flag；postBuild 只补 `bin/bqqnt`（`--set LD_PRELOAD=bstar`）与 `qq2.desktop`。要点：(1) `makeWrapper` 不能写到已存在且指向 store 的 symlink 上（对只读 store `echo > $wrapper` 会 EACCES），先 `rm -f`；(2) `sed -i` 会把 store symlink 换成真文件，不会改到 store 原件；(3) `symlinkJoin` 不继承 `meta`，`description`/`platforms` 要自己给（`meta = qq.meta // { … }`；此时 `meta.position` 落在自己的文件上，`tools/build_own_cachix.py` 会把它算作自有包，而继承上游 meta 会被它的路径过滤掉）；(4) 上游 wrapper 用 `--prefix LD_PRELOAD` 追加自己的库（nixpkgs 的 qq 插 libssh2），外层 `--set LD_PRELOAD=bstar` 不会被清掉，两个库都加载。
- **无 GUI 验证法**：把 `qq` 换成打印 `"$@"`/`$LD_PRELOAD` 的 stub（`callPackage … { pkgs = pkgs // { qq = stub; }; }`）即可断言注入与参数都在；若要在自己的 wrapper 里补 flag，条件写法是 `--add-flags "\''${NIXOS_OZONE_WL:+\''${WAYLAND_DISPLAY:+…}}"`（只有 `\''${` 同时躲开 Nix 插值并把 `$` 留给运行时 shell）。
